# Research continuation plan

These are design hypotheses for future measurement, not completed product
claims, paper replications, or accepted Exitbind requirements. Future public
claims must verify primary-source details and exact experimental conditions
before publication.

| Question | Minimum future experiment | Required observation | Current status | Next step |
| --- | --- | --- | --- | --- |
| Functional success vs preserved requirements | Run the paired env-precedence fixture and one candidate route with the same invariant, if a public product route exists. | Ordinary check result, preservation check result, raw output reference, and product/Holytail measurement availability. | Fixture-only. | Name or add a public product observation route before claiming product detection. |
| Quality and origin of the check itself | Record checker identity/source for the env-precedence known-good and known-bad inputs. | Checker source, exact command, known-good pass, known-bad fail. | Fixture-only. | Add checker calibration cases only after the single pair remains stable. |
| Main agent vs subagent cost | Compare identical requirements and checks across native main-agent and subagent runs. | Identified usage source for tokens/cost, latency, retries, interventions, and final evidence. | Planned. | Use native-host usage records only; missing usage remains unavailable. |
| Defect disclosure / escalation | Pair a defective-check case with a valid-check control. | Whether the agent reports a real conflict instead of cheating, avoiding valid work, or treating the bad check as proof. | Planned. | Define the defective check and the valid control before any run. |
| Residual handoff / do not restart | Run a handoff where the next actor receives current subject, valid evidence, confirmed effects, and remaining obligations. | Duplicate-action rate, skipped-obligation rate, and raw handoff facts. | Planned. | Freeze the handoff fact list and one deterministic continuation task. |
| Shared reviewer errors | Compare joint misses against independent ground truth. | Independent ground truth, reviewer decisions, shared misses, and disagreement data. | Planned. | Do not fabricate correlation; run actual reviewer trials later. |
| Verifiable failure detection | Name concrete events for planned faults before execution. | Event or signal for each fault, plus null/unavailable when no event was captured. | Planned. | Add instrumentation only when a specific event is required by an experiment. |
